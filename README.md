# Read Aloud Maker

I created this to help educators provide read aloud services to students with exceptionalities. In my experience as a teacher, there is never a moment where there isn't some work to be done. To help alleviate that for my peers, 
I created this program to help automate some part of their job. 

This program has users connect to Google Drive to be able to create folders of read alouds with each individual question & answers separated. 

It parses through an uploaded PDF and searches for a number, combined with either a '.' or a ')' to determine if it is a question. It uses those delimiters to separate each question. 

The program reads a PDF line by line, so multi-column tests are not supported. 

As of right now, this only supports multiple choice tests, where each question is separated by a '.' or a ')'. 

I will be working on adding more features and having it support reading passages as well.
